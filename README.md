# Template Undangan Digital (Wedding Invitation)

Selamat datang di *source code* Template Undangan Digital. Template ini dibangun dengan teknologi modern **Next.js 15, React 19, Tailwind CSS**, dan terintegrasi dengan **Supabase** untuk menyimpan daftar tamu/buku tamu.

Dokumen ini disusun agar Anda mudah mempelajari, mengembangkan, dan menyesuaikan undangan ini dengan informasi nyata, maupun jika Anda ingin menjualnya kembali.

---

## 1. Fitur Utama
- **Responsive Design**: Tampilan yang rapi di layar HP maupun Desktop.
- **Kartu Nama Otomatis**: Mendukung integrasi dengan parameter *query* URL (`?to=Nama+Tamu`) untuk menyebutkan langsung nama penerima di cover undangan.
- **Buku Tamu / RSVP**: Tamu bisa mengirimkan ucapan secara *realtime* (terhubung via Supabase).
- **Galeri Foto**: Bagian menarik untuk menampilkan foto pre-wedding secara estetik.
- **Fitur Custom (Musik & Video)**: Terdapat pemutar musik dan efek suara panggilan (*video/voice call*).
- **Mudah Dikustomisasi**: Data statis (tanggal, lokasi, nama) dikumpulkan dalam 1 file `config.ts` sehingga Anda tanpa perlu mengerti kompleksitas *coding* bisa langsung mengedit datanya dengan gampang.

---

## 2. Persiapan Awal (Prerequisites)
Sebelum menjalankan proyek ini, pastikan komputer/laptop Anda telah terinstal beberapa aplikasi wajib berikut:
- [Node.js](https://nodejs.org/) (Sangat disarankan memakai v18 ke atas)
- Editor Teks/Kode (Sangat disarankan menggunakan [Visual Studio Code](https://code.visualstudio.com/))
- (Opsional) [Git](https://git-scm.com/) jika ingin menyimpan di Github dan melakukan deployment ke Vercel via Github.
- Akun [Supabase](https://supabase.com/) untuk fitur buku tamu & ucapan.

---

## 3. Cara Menjalankan Project (Lokal)
1. **Download atau Clone Project**
   Buka folder project undangan di Visual Studio Code.
2. **Buka Terminal VS Code**
   Pilih menu `Terminal` > `New Terminal`. Pastikan sudah berada di dalam folder project (path sudah sesuai).
3. **Instalasi Dependensi / Modul**
   Ketik perintah berikut lalu tekan Enter:
   ```bash
   npm install
   ```
4. **Jalankan Aplikasi**
   Setelah instalasi selesai, jalankan perintah:
   ```bash
   npm run dev
   ```
5. Buka web browser kesayangan Anda (Google Chrome, Safari, dll) dan akses URL: **[http://localhost:3000](http://localhost:3000)**. 
6. Halaman undangan kini sudah bisa dilihat secara live, setiap kali Anda menyimpan perubahan kode, halaman akan reload secara otomatis.

---

## 4. Cara Mengubah Data Undangan (Kustomisasi)

Bagian terbaik dari template ini adalah **kemudahan kustomisasi**. Anda cukup fokus mengedit satu folder khusus tanpa perlu kebingungan dengan ribuan baris kode lainnya.

### Mengubah Teks, Nama, Lokasi, dan Tanggal
1. Buka file bernama: **`src/lib/config.ts`**
2. Di dalam file ini, Anda akan menjumpai variabel bernama `SITECONFIG`, `METADATA`, dan konfigurasi teks lain.
3. Anda bebas mengganti *string* (teks yang berada di dalam tanda kutip ganda). Contoh:
   ```typescript
   groomName: "Nama Mempelai Pria",
   brideName: "Nama Mempelai Wanita",
   linkMap: "Link Google Maps Baru Anda...",
   noRekening: "0000 0000 00",
   bankName: "BCA",
   // dan seterusnya..
   ```

### Mengubah Assets (Foto, Musik, Ikon, dsb)
Semua file media berada di dalam direktori **`public/assets`**.
- **Foto Prewed**: Berada di folder `public/assets/prewed/`. Jika Anda memasukkan foto baru, ubah rujukan nama file-nya juga di dalam array `GALLERY_IMAGES` di dalam `src/lib/config.ts`.
- **Musik & Video**: Terdapat aset `tenxi-bintang5.mp3` dan `video-call.mp4`. Ganti file ini jika Anda ingin mengganti *background audio* & *video call*. Atau sesuaikan namanya di dalam `src/lib/config.ts`.
- **Informasi / Meta Image**: Untuk merubah thumbnail ketika link disebar ke WhatsApp/Facebook, ganti gambar `public/assets/og-image.png`.

## 5. Setting Supabase (Fitur Buku Tamu / Ucapan)

Daftar ucapan di website ini akan terhubung secara *real-time* dengan database Supabase. Jika tidak disetting, maka pesan tidak akan masuk atau error.

1. Buka [Supabase](https://supabase.com/) dan silakan Buat Project Baru.
2. Klik navigasi menu **SQL Editor**, jalankan skrip SQL di bawah ini untuk membuat tabel:
   ```sql
   create table public.messages (
     id bigint generated by default as identity,
     created_at timestamp with time zone not null default now(),
     name text null,
     message text null,
     is_anonymous boolean null,
     constraint messages_pkey primary key (id)
   );
   ```
3. *(Penting)* Matikan **RLS (Row Level Security)** pada tabel ini (klik tabel `messages` lalu matikan dari menu Authentication/Table editor), atau Anda bisa membuat policy untuk memberikan hak akses Read/Write secara publik.
4. Duplikat atau *rename* file `.env.example` di dalam project Anda menjadi `.env`
5. Buka dan masukkan kredensial dari project Supabase Anda (Bisa dilihat di: Project Settings -> API):
   ```env
   BASE_URL="http://localhost:3000"
   NEXT_PUBLIC_SUPABASE_URL="URL_PROJECT_SUPABASE_ANDA"
   NEXT_PUBLIC_SUPABASE_ANON_KEY="ANON_KEY_ANDA"
   SUPABASE_URL="URL_PROJECT_SUPABASE_ANDA"
   SUPABASE_SERVICE_ROLE_KEY="SERVICE_ROLE_KEY_ANDA"
   ```
   *Catatan: SERVICE_ROLE_KEY bersifat rahasia, sangat tidak disarankan terekspos ke publik.*

## 6. Hosting / Deployment
Jika sudah puas dengan semua perubahan/custom data yang dilakukan di komputer Anda, saatnya meng-onlinekan undangan! Tempat gratis yang kami rekomendasikan adalah Vercel.

1. Silakan unggah *(push)* folder project (yang telah Anda edit) ke akun Github Anda terlebih dahulu.
2. Login ke **[Vercel](https://vercel.com/)** menggunakan Github.
3. Klik tombol **Add New Project**, dan pilih project/repository Github undangan Anda.
4. **Tahap Paling Penting:** Pada bagian `Environment Variables` *sebelum/saat menekan tombol deploy*, isikan semua variable beserta isinya yang ada di file `.env` (seperti Supabase URL, BASE URL, dll). Oh iya, ganti `BASE_URL` dari `http://localhost:3000` menjadi domain gratis Vercel Anda nantinya.
5. Klik **Deploy** dan tunggu proses berjalan selama 1-2 menit.
6. Selesai! Web Undangan Anda berhasil mengudara! (Anda kini bisa menyebar link undangan kepada para tamu seperti: `www.web-anda.vercel.app?to=Nama+Tamu`).
